# 🎬 Exploratory Data Analysis of IMDb Movies using SQL & Power BI

## 📌 Project Overview
This project performs exploratory data analysis (EDA) on the IMDb Movies dataset
using SQL and presents insights through an interactive Power BI dashboard
to support data-driven decision-making.

## 🛠 Tools & Technologies
- SQL (Data Cleaning, Aggregation, Analysis)
- Power BI (Data Modeling & Visualization)
- Power Query
- DAX (Basic Measures)

## 🔍 Key Business Questions
- Which movies have the highest votes and revenue?
- Which directors are most productive?
- How has movie production changed over the years?
- Which genres dominate the movie industry?

## 📊 Analysis Performed
- Data validation and cleaning (NULL and empty value checks)
- Top movies analysis based on votes and revenue
- Director-wise movie count analysis
- Year-wise movie release trends
- Genre-based movie distribution analysis

## 📈 Power BI Dashboard Highlights
- Top 8 movies by votes
- Top 6 movies by revenue
- Director productivity analysis
- Year-wise movie release trends
- Interactive filters by year, title, and director

## 💡 Key Insights
- A small group of movies receive a disproportionately high number of votes.
- Certain directors consistently release more movies than others.
- Movie releases have increased significantly in recent years.
- Drama and Action genres dominate the dataset.
